# Data & Drafts: a neighborhood data deep dive

Explore housing and neighborhood change in Indianapolis with R.

Our default examples compare Meridian Hills/Williams Creek, East Warren, Arlington Woods, and Near Southside.

## Start here

- `data/` holds the tables and map boundaries.
- `scripts/Explore_Neighborhoods.R` is the main script for the event.
- `products/` holds the plots and maps you make.
- `renv.lock` records the R package versions used by the project.
